# Security Policy

CAGovAI is a set of policy documents and templates, not running software. Security issues here are mostly about **content**: guidance that would weaken a State Entity's security or privacy if followed, or information that should not be public.

## What to report privately
Use **[Report a vulnerability](https://github.com/Spherical5308/CAGovAI/security/advisories/new)** (GitHub private vulnerability reporting) for:
- a control, standard or procedure that, if adopted as written, would create a security or privacy weakness;
- anything in the repository that looks like real non-public information: names, internal systems, network details, completed risk assessments, credentials or personal data;
- a problem with a script or workflow in this repository.

Please include the file, the section, what the risk is, and a suggested fix if you have one. Do not include sensitive details from your own organisation.

## What not to report here
- **Incidents at a State Entity.** Report those through your entity's Information Security Officer and the State's incident process (SIMM 5340-A), not to this project.
- **Ordinary errors** such as a wrong or outdated citation. Open a normal issue using the "Citation or legal error" template.

## What to expect
The maintainer aims to acknowledge a report within 5 business days, agree on a fix, and publish it in the [CHANGELOG](./CHANGELOG.md). This is a volunteer project with no service-level commitment.

## Supported versions
Only the latest release and the `main` branch are maintained.
