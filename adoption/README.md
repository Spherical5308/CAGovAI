# Adoption Kit

Everything a State Entity needs to put the framework into effect, beyond the documents themselves.

| Document | What it is | Who uses it |
|---|---|---|
| [90-Day Rollout Plan](./90-Day-Rollout-Plan.md) | Week-by-week tasks from six weeks before the effective date to the close of the Legacy Use registration window, then the steady-state rhythm | Executive Sponsor, AI Governance Coordinator |
| [Committee Kickoff Agenda](./Committee-Kickoff-Agenda.md) | Agenda and pre-reads for the Committee's first meeting, plus a standing monthly agenda | Chair, Coordinator |
| [GenAI Training Outline](./GenAI-Training-Outline.md) | Role-based training modules mapped to SAM 4986.13 | HR/Training, managers |
| [Placeholder Checklist](./Placeholder-Checklist.md) | Every bracketed value to replace before adoption | Coordinator |

## Suggested order
1. Work through the [Placeholder Checklist](./Placeholder-Checklist.md) while the Director appoints the people in Phase 1 of the [Rollout Plan](./90-Day-Rollout-Plan.md).
2. Line up training from the [Training Outline](./GenAI-Training-Outline.md) so it is ready on Day 0.
3. Hold the first Committee meeting with the [Kickoff Agenda](./Committee-Kickoff-Agenda.md) in the first two weeks.

Constitutional offices and other non-Executive Branch entities can use the kit as written; see the [Non-Executive Branch adoption note](../docs/Non-Executive-Branch-Adoption.md) for which SAM sections bind them.
