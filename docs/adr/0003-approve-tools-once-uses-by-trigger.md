# Approve Tools once; Use Cases need a Request only when a Trigger is hit

A Tool is approved once with a list of Approved Uses (modelled on SIMM 150 categories and Oregon's Copilot use matrix). Staff using a Tool inside its Approved Uses file no Request; a Request is required only when a Trigger is hit. This keeps the AI Governance Committee's attention on material risk and avoids routine office use being driven into shadow AI.
