# One intake for all AI, not just GenAI

SAM 4986.1–.13 and SIMM 5305-F cover GenAI only, but GC 11546.45.5 also requires an inventory of high-risk automated decision systems that may not be generative. We run a single Request process and inventory for all AI, layering the GenAI-specific SAM 4986 requirements on when the Tool is generative, rather than two parallel processes.
